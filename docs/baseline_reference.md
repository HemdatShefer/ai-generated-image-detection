# Baseline Reference

This project was inspired by an external baseline implementation for classifying real and AI generated images.

The baseline code was used as a starting point for research, experimentation, and improvement.

The original baseline implementation is not included as authored source code in this repository because it was not written by me.

My work in this project focused on understanding the baseline approach, experimenting with preprocessing and model usage, organizing the project structure, and integrating the model into an application flow.
